# Генератор случайных пользователей (Random User Generator)

Небольшое приложение, которое запрашивает данные случайного человека через открытое API и выводит их в виде красивой карточки профиля. 

Создано для отработки навыков работы с асинхронным JavaScript и внешними REST API.

## ✨ Возможности

- **Интеграция с API**: Запрос данных с `https://randomuser.me/api/`.
- **Обработка асинхронности**: Использование `async / await` и `try...catch` для обработки ошибок сети.
- **UX/UI состояния**: Кнопка блокируется на время загрузки (меняется текст на "Загрузка..."), чтобы предотвратить спам запросами.
- **Форматирование данных**: 
  - Дата рождения конвертируется из формата ISO в привычный `ДД.ММ.ГГГГ`.
  - Пол автоматически переводится на русский язык (`male` -> `Мужской`).
  - Адрес объединяется в строку (Город, Страна).
- **Адаптивный дизайн**: На мобильных устройствах карточка перестраивается в колонку (аватар перемещается наверх) с помощью `flex-direction: column-reverse`.
- **Защита от редактирования**: Поля ввода имеют атрибут `readonly`, чтобы пользователь случайно не изменил данные кандидата.

## 🛠 Стек технологий

- **HTML5** (семантика, правильные типы инпутов: `email`, `tel`, `password`)
- **CSS3** (Flexbox, тени, плавные hover-эффекты кнопок, медиа-запросы)
- **Vanilla JavaScript** (Fetch API, Promise, DOM Manipulation)
- Без использования сторонних библиотек и фреймворков.

## 🚀 Как запустить

Проект не требует установки зависимостей и сборки.
1. Скачайте файлы или склонируйте репозиторий.
2. Откройте файл `index.html` в любом современном браузере.
3. Нажмите кнопку **"Найти нового!"** (потребуется интернет для запроса к API).
